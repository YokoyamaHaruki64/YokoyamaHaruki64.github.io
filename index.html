BEHIND THE CODE
✳

遊び心と、
技術のあいだ。

ゲームづくりで大切にしたいこと。

以下は紹介文の仮原稿です。
01

触って気持ちいい体験を。

入力への反応、キャラクターの動き、画面の変化。小さな手触りまで考えたゲームをつくっていきたいです。

02

変化を受け止める設計を。

試して、直して、また試す。その繰り返しを支えられるように、機能の役割が分かるコードを目指します。

03

「なぜ？」を、その先へ。

動いた理由も、動かなかった理由も確かめる。気づきを次の制作に活かしながら、できることを広げていきたいです。
